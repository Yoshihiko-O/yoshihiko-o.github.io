Dreave トレーナー機能 仕様書

バージョン: 1.0 作成日: 2026-05-19 作成者: Yoshihiko

概要

Dreave は「明晰夢トレーナー」として、ユーザーが明晰夢を習得・深化できるよう能動的に関与するアプリを目指します。ツール（受動的）ではなくトレーナー（能動的）として機能するために、ロードマップに沿った3つのフェーズで機能を追加していきます。

最も重要な課題: 明晰夢習得における最大のハードルは 4〜14日目の離脱 です。効果が現れるまでに時間がかかり、「何をすればいいか分からない」状態に陥りやすいため、トレーナー機能はこの壁を越えさせることを最優先とします。

ロードマップ

段階的にアプリ価値を高め、ユーザーの習熟度と継続率を高める3段階のフェーズ計画です。

フェーズ リリース 内容
Phase 1 v1.0 (分析強化) 分析・振り返り強化（Night Mode効果、明晰夢率推移、ドリームサイン）
Phase 2 v1.1 (コーチング) コーチングメッセージ + マイルストーン + 課金有効化（Pro機能解放）
Phase 3 v1.2 (カリキュラム) トレーニングカリキュラム + 体験の深化（ドリームバケットリスト）

Phase 1：分析・振り返り強化（v1.0）

ユーザー自身で気づくことが難しい夢の相関データやパターンを可視化し、翌朝の記録や振り返りそのものを価値のある体験に変えます。

1-1. Night Mode 効果グラフ

目的: Night Mode（音響刺激などの配信機能）の使用と夢の質の相関を可視化し、継続動機を作ります。「Night Mode を使った週は明晰夢が多い」というデータが出れば、Phase 2 で導入するPro課金への強力な動機付けになります。

表示内容:

  • Night Mode 使用日 / 非使用日 それぞれの平均 Recall Score（夢の想起度）を比較するバーチャート
  • サマリー文：「Night Mode 使用日の平均スコアは N ポイント高い」

1-2. 明晰夢率の推移グラフ

目的: 単に「明晰夢を見た数」という累積値ではなく、「いつ頃から出始めたか」という時系列の確率推移を見せることで、日々の継続による確かな手応えを伝えます。

表示内容:

  • 週ごとの明晰夢率（明晰夢数 ÷ 総夢記録数）を折れ線グラフで表示
  • y 軸：0〜100%（または 0〜1.0）

1-3. ドリームサインカード

目的: 夢に繰り返し登場するテーマやシンボルを提示し、「自分の夢のパターン」への気づきを促します。これは明晰夢習得の第2ステップ（夢であるサインの特定）に直結します。

表示内容:

  • AI 分析済みの夢から抽出した上位テーマ（最大5件）をタグ形式で表示
  • 上位シンボル（最大5件）を同様に表示
  • 「これがあなたのドリームサイン候補です」という説明文

Phase 2：コーチングメッセージ + マイルストーン（v1.1）

能動的な「トレーナー」として振る舞い、最も挫折しやすいタイミングでアドバイスを送り、達成を称えるゲーム感覚のシステムを導入します。

2-1. コーチングメッセージ

目的: ユーザーの現在状態や記録頻度、明晰夢の有無に応じて「次に何をすべきか」を個別最適化されたテキストで伝えます。4〜14日目の離脱防止における最大のキーマンです。

表示箇所: Dashboard のトップカード（既存サマリーの上）

2-2. マイルストーン

目的: 小さなステップでの達成感を可視化します。特に「初めての明晰夢（First Lucid）」を達成した瞬間は、最高のお祝いエフェクトで飾り、アプリ体験の中で忘れられない強烈なモーメントを演出します。

Phase 3：トレーニングカリキュラム（v1.2）

明晰夢をランダムな出来事から「トレーニング可能な技術」へと昇華させます。

3-1. 5段階カリキュラム

ユーザーが現在どのステップにいるかを常に可視化し、「次にすべき行動」へ迷わないように設計されたトレーニング課程です。

Stage 1: 夢の想起力を高める (1〜7日)
条件: 夢記録7日連続

夢日記を習慣づけ、目覚めた直後に夢を細部まで思い出す脳の回路を活性化します。

Stage 2: ドリームサインを見つける (8〜14日)
条件: AI分析でテーマ3件

自分の夢に繰り返し出現する「鍵（シンボルやシチュエーション）」を特定します。

Stage 3: リアリティチェックを習慣化 (15〜21日)
条件: チェック3日連続

日常の中に「今、自分は夢の中にいるか？」を確認する動作（習慣）を埋め込みます。

Stage 4: 誘発テクニックを使う (22〜30日)
条件: Night Mode 3回

WBTB（二度寝法）やMILD法に、アプリのNight Mode音響ガイドを連動して実践します。

3-2. 体験の深化（ドリームバケットリスト）

明晰夢を見ることに成功したあと、アプリを使い続ける動機付けとしての「夢の中のやることリスト」機能です。達成した項目には、当時の夢日記（夢記録）をリンクさせて振り返ることができます。

カテゴリ例: 冒険系（空を飛ぶ、過去に行く）、セラピー系（トラウマの克服、恐怖との対話）、クリエイティブ系（脳内での作曲やアイデア出し）など。

技術メモ

開発陣向けのロジック抜粋および実装定義の解説です。

CoachingMessageEngine の評価順序

複数条件が重なる場合は、優先度の最も高いメッセージを1つだけ採択します。評価トリガーは「アプリ起動時」「新規の夢記録保存時」「日付が変更されたとき」とします。

Night Mode 効果グラフの算出ロジック (Swift)

Swift 
// 1. Night Mode使用日の特定
let nightModeDates = nightSessions
    .filter { $0.endReason != "cancelled" }
    .map { Calendar.current.startOfDay(for: $0.startedAt) }
    .reduce(into: Set<Date>()) { $0.insert($1) }

// 2. その日の夢Recall Scoreを照合して分離
let withNightMode = dreams.filter { 
    nightModeDates.contains(Calendar.current.startOfDay(for: $0.recordedAt)) 
}
let withoutNightMode = dreams.filter { 
    !nightModeDates.contains(Calendar.current.startOfDay(for: $0.recordedAt)) 
}
