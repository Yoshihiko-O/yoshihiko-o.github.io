Dream Pass について

Dreave の Night Mode は「Dream Pass」制です。無料プランでも毎週 3 回まで Night Mode を使用でき、追加で使いたい夜はリワード広告で補充できます。

  • 週 3 回の無料枠: 毎週月曜 0:00 に自動リセット。週 3 回分の Night Mode が付与されます。
  • リワード広告で補充: Pass が不足した場合、約 30 秒のリワード広告を視聴することで 1 日 1 回まで補充できます。
  • 初回トライアル: 初回インストールから 7 日間は Night Mode が無制限で使用できます。
  • Dreave Pro の場合: Dream Pass の制限がなくなり、いつでも何回でも Night Mode を使用可能です。

よくある質問

Dreave Pro は一度買えばずっと使えますか？
はい。月額課金（サブスクリプション）ではなく「買い切り型」のライセンスです。一度の購入で、将来追加される Pro 機能も含めて永続的にご利用いただけます。
Dream Pass が足りなくなったらどうすればいいですか？
毎週月曜日の自動リセットを待つか、リワード広告を視聴することで 1 日 1 回までパスを補充できます。制限なしで使いたい場合は、Dreave Pro へのアップグレードをご検討ください。
機種変更しても Pro 権限は引き継げますか？
はい、同じ Apple ID を使用していれば、新しい端末でも「購入内容の復元（Restore）」を行うことで引き続きご利用いただけます。
Android や iPad 対応はありますか？
現在は iPhone (iOS 17 以上) 専用アプリとなっています。iPad でも動作はしますが、枕元に置く特性上、iPhone での使用を推奨しています。
